# Chicago Crime Data Analysis

## Project Overview

This project is an exploratory analysis of Chicago crime data using Python.

I built this project to get more experience working with a real-world dataset instead of only practicing with small examples. My main goal was to clean the data, explore it, and find useful patterns in crime types and when crimes happen.

## Questions I Wanted to Answer

While working on the dataset, I focused on a few simple questions:

* What are the most common types of crime?
* What time of day are more crimes reported?
* Does crime change depending on the day of the week?
* What useful patterns can I find from the data?

## Dataset

The project uses public Chicago crime data.

The dataset contains information such as the type of crime, date and time, location information, arrest status, district, and other crime-related details.

The full dataset is not included in this repository because of its large file size.

## Tools Used

* Python
* pandas
* matplotlib
* Jupyter Notebook
* Data Cleaning
* Exploratory Data Analysis (EDA)

## What I Did

1. Loaded and explored the dataset
2. Checked the columns, data types, and missing values
3. Cleaned the data and removed unnecessary columns
4. Prepared date and time information for analysis
5. Analyzed the most common crime types
6. Compared crime activity by hour and day of the week
7. Created visualizations using matplotlib
8. Wrote simple insights based on the results

## Key Findings

Some of the main things I found were:

* Theft was the most common crime type in the dataset.
* Battery and criminal damage were also among the most common crimes.
* Crime was lowest during the early morning hours and increased later in the day.
* Crime totals were fairly similar across the different days of the week.

## What I Learned

This project gave me more practice working with a large real-world dataset.

I improved my understanding of pandas, especially for cleaning, filtering, working with dates, and analyzing data. I also got more comfortable using matplotlib to turn the results into visualizations instead of only looking at numbers.

Most importantly, this project helped me understand the full process of taking raw data, cleaning it, asking questions, and turning the results into useful insights.
